# Cookie Shop Sample Request Platform

## Description
This project is a sample request platform for a cookie shop tailored for bulk orders, such as weddings or large events. Customers can use the website to fill out a form to request a sample, helping them decide on flavors for significant occasions. The platform is not an e-commerce site; it focuses solely on facilitating sample requests.

### Tech Stack

- **Frontend**: Nuxt 3 (Vue.js) for a smooth user experience
- **Styling**: Tailwind CSS for a modern and responsive design
- **Database**: Supabase for secure data storage
- **Authentication**: Third-party login options for user convenience
- **Data Management**: Prisma for structured data handling and optimized querying

---

## 項目簡介
這是一個專為餅乾店設計的試吃申請平台，適合需要大量訂購的客戶（如婚禮或大型活動）。客戶可以通過網站填寫表單申請試吃，以便選擇最合適的口味。此平台並非電商網站，而是專注於協助客戶進行樣品試吃申請。

### 技術棧

- **前端**: Nuxt 3（Vue.js）提供流暢的用戶體驗
- **樣式**: 使用 Tailwind CSS 來設計現代化的響應式界面
- **數據庫**: 利用 Supabase 進行安全的數據存儲
- **身份驗證**: 第三方登入方式，方便用戶
- **數據管理**: 使用 Prisma 來處理數據結構並進行優化查詢
